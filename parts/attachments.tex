Složka \texttt{own-work} obsahuje realizaci formálního modelu ze sekce~\ref{sec:model} v~jazyce TypeScript a~testy,~které ověřují jeho tvrzení. Hlavní výsledky shrnuje podsekce~\ref{sec:model-typescript}.

\paragraph{Spuštění.}
Testy vyžadují prostředí Node.js,~které spouští soubory TypeScriptu přímo. Ověřeny byly ve verzi~26.11.1. Ve složce \texttt{own-work} jsou spouštěny příkazy
\begin{minted}{text}
npm install
npm test
\end{minted}
\noindent
Příkaz \texttt{npm test} nejprve vygeneruje překladové testy do složky \texttt{test/generated}, poté zkontroluje realizaci i~testy překladačem \texttt{tsc} v~přísném režimu (\texttt{strict}) a~nakonec spustí testy za běhu nástrojem \texttt{node:test}. Použity jsou TypeScript~7.0.2, Zod~4.6.5, parser HTML5 \texttt{parse5}~8.0.1 a~knihovna \texttt{fast-check}~4.10.2,~která generuje náhodné programy a~vstupy útočníka. Generátory mají pevná semínka, takže každý běh dává stejná čísla. Mutační kontrolu z~podsekce~\ref{sec:model-overeni} spouští příkaz \texttt{npm run mutants}. Trvá několik minut a~součástí \texttt{npm test} není.

\paragraph{Obsah složky.}
\begin{itemize}
    \item \texttt{src/label.ts}: štítek podle výpisu z~podsekce~\ref{sec:model-typescript} a~funkce \texttt{cat} pro pravidlo \textsc{T-Concat};
    \item \texttt{src/contexts.ts}: spodní odhady množin $\CtxOf(s)$ a~$D(S)$, každý jako typ pro překladač a~jako funkce pro testy za běhu;
    \item \texttt{src/index.ts}: funkce \texttt{h}, \texttt{parse}, \texttt{sanitize}, \texttt{send} a~\texttt{out} pro ostatní pravidla z~tabulky~\ref{tab:pravidla}, sanitační funkce pro kontexty \emph{html}, \emph{script} a~\emph{url} a~jejich deklarace;
    \item \texttt{src/tpl.ts}: skener šablon jako typ (pravidlo \textsc{T-Tpl}), funkce \texttt{html} a~běhové dvojče skeneru \texttt{walk};
    \item \texttt{lib/index.ts} a~\texttt{lib/unsafe.ts}: veřejné rozhraní knihovny ze sekce~\ref{sec:lib} a~úniky z~typového systému;
    \item \texttt{test/model.ts}: interpret jazyka modelu,~který u~každého znaku výsledku sleduje jeho původ (množinu~$U(s)$), a~generátory programů a~útoků;
    \item \texttt{test/oracle.ts}: model prohlížeče podle předpokladu~\ref{ass:parse} nad parserem \texttt{parse5};
    \item \texttt{test/compile}: překladové testy,~ve kterých řádek s~direktivou \texttt{@ts-expect-error} musí skončit chybou a~každý jiný se musí přeložit;
    \item \texttt{test/enumerate.ts}: úplné vyčíslení výrazů modelu do dané velikosti nad sadou stavebních kamenů generátoru;
    \item \texttt{scripts/generate.ts}: skript,~který do složky \texttt{test/generated} vygeneruje další překladové testy;
    \item \texttt{scripts/mutants.ts}: mutační kontrola z~podsekce~\ref{sec:model-overeni}, výčet mutantů hlídá test \texttt{mutants.test.ts};
    \item \texttt{test/*.test.ts}: testy za běhu.
\end{itemize}

Model prohlížeče je zjednodušený. Do množiny~$V$ řadí těla skriptů kromě obsahu řetězcových literálů, do kterých zapisuje propast nebo díra šablony. Jiné řetězcové literály zůstávají označeny, protože model nemá lexer JavaScriptu. Množinu tím nadhodnocuje,~což je pro podmínku vlastní netečnosti bezpečný směr. Dále do množiny~$V$ řadí hodnoty obsluh událostí a~atributu \texttt{srcdoc}, hodnoty se schématy \texttt{javascript:}, \texttt{vbscript:} a~\texttt{data:} mimo textové atributy, atributy \texttt{src} a~\texttt{href} skriptu, \texttt{href} elementu \texttt{base}, \texttt{data} elementu \texttt{object} a~\texttt{src} elementu \texttt{embed}.

Textovými atributy jsou \texttt{alt}, \texttt{class}, \texttt{id}, \texttt{for}, \texttt{name}, \texttt{placeholder}, \texttt{title}, \texttt{value}, \texttt{label}, \texttt{lang}, \texttt{dir}, \texttt{role}, \texttt{tabindex}, \texttt{rows}, \texttt{cols}, \texttt{size}, \texttt{maxlength}, \texttt{width}, \texttt{height} a~atributy s~předponou \texttt{aria-} a~\texttt{data-}. Elementy načítající kód, na kterých díra není dovolena, jsou \texttt{script}, \texttt{base}, \texttt{object}, \texttt{embed}, \texttt{applet} a~\texttt{param}.

Datová díra kontextu \emph{text} je stav tokenizéru RCDATA (obsah elementů \texttt{title} a~\texttt{textarea}), hodnota textového atributu v~uvozovkách, nebo stav Data za značkou \texttt{title},~kterou prohlížeč zahodil (uvnitř elementu \texttt{select}), dokud nepřijde její koncová značka. Prefixy~$P$ kontextu \emph{text} proto obsahují i~\texttt{<select><option><title>}. Typové balíky Expressu a~Fastify slouží jen překladovému testu funkce \texttt{send}. Tabulka~\ref{tab:own-work} přiřazuje tvrzením modelu testy,~které je ověřují. Cesty v~ní jsou uvedeny vůči složce \texttt{test}.

Tvrzení o~štítcích jsou tak testy dokázána vyčerpáním všech případů, tvrzení o~řetězcích a~programech jen podpořena. Platí pro vyzkoušené programy, pro všechny malé programy nad sadou kamenů a~vůči uvedenému modelu prohlížeče, nikoliv pro všechny programy a~skutečné prohlížeče.
