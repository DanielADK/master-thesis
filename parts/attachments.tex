Složka \texttt{own-work} obsahuje realizaci formálního modelu ze sekce~\ref{sec:model} v~jazyce TypeScript a~testy,~které ověřují jeho tvrzení. Hlavní výsledky shrnuje podsekce~\ref{sec:model-typescript}.

\paragraph{Spuštění.}
Testy vyžadují prostředí Node.js,~které spouští soubory TypeScriptu přímo. Ověřeny byly ve verzi~26.11.1. Ve složce \texttt{own-work} jsou spouštěny příkazy
\begin{minted}{text}
npm install
npm test
\end{minted}
\noindent
Příkaz \texttt{npm test} nejprve vygeneruje překladové testy do složky \texttt{test/generated}, poté zkontroluje realizaci i~testy překladačem \texttt{tsc} v~přísném režimu (\texttt{strict}) a~nakonec spustí testy za běhu nástrojem \texttt{node:test}. Použity jsou TypeScript~7.0.2, Zod~4.6.5, parser HTML5 \texttt{parse5}~8.0.1 a~knihovna \texttt{fast-check}~4.10.2,~která generuje náhodné programy a~vstupy útočníka. Generátory mají pevná semínka, takže každý běh dává stejná čísla.

\paragraph{Obsah složky.}
\begin{itemize}
    \item \texttt{src/label.ts}: štítek podle výpisu z~podsekce~\ref{sec:model-typescript} a~funkce \texttt{cat} pro pravidlo \textsc{T-Concat};
    \item \texttt{src/contexts.ts}: spodní odhady množin $\CtxOf(s)$ a~$D(S)$, každý jako typ pro překladač a~jako funkce pro testy za běhu;
    \item \texttt{src/index.ts}: funkce \texttt{h}, \texttt{parse}, \texttt{sanitize}, \texttt{send} a~\texttt{out} pro ostatní pravidla z~tabulky~\ref{tab:pravidla} a~sanitační funkce pro kontexty \emph{html}, \emph{script} a~\emph{url};
    \item \texttt{test/model.ts}: interpret jazyka modelu,~který u~každého znaku výsledku sleduje jeho původ (množinu~$U(s)$), a~generátory programů a~útoků;
    \item \texttt{test/oracle.ts}: model prohlížeče podle předpokladu~\ref{ass:parse} nad parserem \texttt{parse5};
    \item \texttt{test/compile}: překladové testy,~ve kterých řádek s~direktivou \texttt{@ts-expect-error} musí skončit chybou a~každý jiný se musí přeložit;
    \item \texttt{scripts/generate.ts}: skript,~který do složky \texttt{test/generated} vygeneruje další překladové testy;
    \item \texttt{test/*.test.ts}: testy za běhu.
\end{itemize}

Model prohlížeče je zjednodušený. Do množiny~$V_c$ řadí těla skriptů (u~kontextu \emph{script} kromě obsahu řetězcového literálu, do kterého propast zapisuje), hodnoty obsluh událostí a~atributu \texttt{srcdoc}, hodnoty se schématy \texttt{javascript:}, \texttt{vbscript:} a~\texttt{data:}, atributy \texttt{src} a~\texttt{href} skriptu a~atribut \texttt{href} elementu \texttt{base}. Tvrzení o~štítcích jsou tak testy dokázána vyčerpáním všech případů, tvrzení o~řetězcích a~programech jen podpořena. Platí pro vyzkoušené programy a~vůči uvedenému modelu prohlížeče, nikoliv pro všechny programy a~skutečné prohlížeče.
